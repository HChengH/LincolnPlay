# LincolnPlay

**为 2020 款林肯飞行家（中规 SYNC+ 破解车机）打造的 Wired CarPlay 接收器，亦适用于类似的 Android 8 车机。** 基于 [DiPlay](https://github.com/shihabal3amri/DiPlay) 移植：同一套接收器，重定了传输、音频与仪表集成。

> 在一辆车上开发并实车验证：2020 飞行家，NXP MEK-MX8Q 主板，Android 8.1（API 27，userdebug）。其他 SYNC+/Freescale 车机可能可用；比亚迪专属代码保留在树中但会自行关闭。与福特、苹果无关。
>

## 实车已验证

- **Android 8.1 有线 USB CarPlay** —— 老栈上的完整点亮：16 KB `UsbRequest` 分块钳制、USB 重枚举生命周期、拔插恢复（有线会话失败后强制干净重枚举而非复用陈旧端点）、稳定的 lockdown 身份 + 配对外置备份（重装 App 不再重新配对）。
- **仪表与 HUD 导航** —— 高德车机广播方言，新老字段双写：箭头、路名、距离按原厂固定功能控件、原厂样式上屏。
- **方向盘与中控按键** —— 方向盘切歌（297/298）与中控 seek 键（294/295）。
- **清晰且可分调音量的导航提示音** —— `/info` 广告对语音类通道去掉 8/12 kHz 位，iPhone 因此发送宽带流（正是后装互联盒的做法）：提示音在导航 usage 上不再发闷，且保留独立音量通路。音乐走 48 kHz LPCM 无损传输。
- **按音频规范调校的压低/恢复** —— 几何增益斜坡（苹果 AudioUnit `Pow` 曲线族），压低 120ms 快攻、恢复 500ms 缓收；提示音轨先排空再释放，到达播报不再被截断；压低提前解除、藏在媒体缓冲延迟后面，恢复不拖沓。
- **仪表歌曲栏** —— `PLAY_INFO` 广播透传正在播放的歌名/歌手（蓝牙音乐式）。若将来有播放器把歌词行写进"正在播放"标题，同一通道自动变成滚动歌词。
- **跟随光线的昼夜切换** —— 环境光传感器 + 自动大灯式双阈值滞回（低于 400 lux 入夜、高于 1000 lux 回昼），连接时以日出日落推算做基线（这块车机经广域嗅探证实没有任何系统级昼夜信号）。
- **60fps 选项与滑动优化** —— 触控移动事件合并抗发送突发、视频层满覆盖时走不透明合成。
- **无处不在的诊断** —— 崩溃安全网（可复制堆栈）、屏幕日志浮层、会话导出、连接各步骤耗时进日志。

## 尚未支持

无线模式、SurfaceView 渲染路径、启动权限并行化。麦克风上行已内置 libopus 软件编码器（Android 8 缺 MediaCodec 的那个）；这块板子的麦克风 DSP 跟随输出音频场景，采集期间由一条静音媒体轨保持通路。
