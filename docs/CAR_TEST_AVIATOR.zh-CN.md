# DiPlay 林肯飞行家移植 · 车测清单

测试包：`F:\DiPlay\diplay-aviator-debug.apk`（`assembleStandaloneDebug` 产物，已含身份资产，统一文件名直接覆盖安装）。
构建：WSL `/root/DiPlay`，`DIPLAY_AUTH_ASSETS_DIR=/root/diplay-auth-assets ./gradlew :mobile:assembleStandaloneDebug`（**所有 gradle 调用都带这个环境变量**，混用会导致配置缓存抖动）。
日志：设置 → 诊断 → 保存报告。日志 512KB 轮转，**导出紧跟测试动作**。

## 核心链路（每次出包必测）

1. **插线连接**：桌面无闪动 → 后台静默连接 → CarPlay 就绪自动浮出（全程 ~13s；手机侧建议卡片先出现是正常两段式）
2. **音乐**：USB 出声、音质正常（提示音钉死宽带 LPCM）
3. **导航播报**：仪表/HUD 箭头路名距离正确；压低即时、恢复平滑（最后一字 ~1.5s 起升 ~2s 到位；分段播报停顿不误回升）
4. **断开**：拔线/自发断 → 直接回车机桌面（非安卓原生启动器）→ 线不动时重连成功自动浮出
5. **卡片路由**：连接中点 DiPlay 卡片直达 CarPlay；无连接时进设置

## 已验证功能（回归抽查）

- 方向盘切歌键 297/298、中控 seek 294/295
- 昼夜：环境光传感器（默认开，400/1000 lux 滞回）
- GPS 回报 iPhone（默认开，首次连接弹一次精确定位授权）
- 麦克风：Siri ✓ / 飞书 ✓；**微信、豆包录音 = 已知未通**（等一次含录音尝试的日志定位流差异）
- 车图标：林肯标 + SYNC+ 名称，CarPlay 里点击回车机桌面
- 返回键 = 回桌面，会话保持；会话菜单 → "DiPlay 设置" 可进设置页

## 待验证 / 进行中

## 已知事实（勿重复排查）

- 插线到出画面 ~13s 的构成：控制面 ~5s（协议顺序）+ 手机回连 AirPlay 6s（待诊断）+ 首帧 2s
- 语音识别/微信录音走 CarPlay 麦克风的前提是广告输入能力（全摘会音乐回落手机喇叭）
- 音源选择与音乐暂停打架无关（全局性）；断蓝牙即好
- 有线重插：`reuse-descriptors` 直连路径 ~12s（勿与首插混淆）
